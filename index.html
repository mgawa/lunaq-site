How it works

Live on-chain checks

  • • Reads BNB balance from BNB Smart Chain RPC
  • • Reads transaction count from wallet nonce
  • • Reads LUNAQ token balance from the BEP-20 contract
  • • Assigns holder tier based on token balance
  • • Generates a wallet trust score based on activity + holdings
This version is lightweight and deployable on GitHub or Vercel without a backend. You can extend it later with BscScan, GoPlus, or your own API.
